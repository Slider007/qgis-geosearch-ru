# Плагин QGIS «Поиск адреса» (GeoSearchRU)

Устройство и возможности — в `README.md`.

## Как выпускать версию

1. `tests/run_tests.sh` — все проверки должны пройти.
2. Поднять `version=` и дописать `changelog=` в `GeoSearchRU/metadata.txt`.
3. После подтверждения — коммит и пуш, затем релиз с архивом:
   `gh release create vX.Y.Z "$(./build_zip.sh)" --title X.Y.Z --notes "…"`.
4. Дальнейшие шаги (рассылка и обновление у себя) — в локальном `CLAUDE.local.md`,
   если он есть: этот файл не публикуется.

## Грабли

- Папка плагина называется `GeoSearchRU` — под этим именем плагин уже стоит у
  пользователей. Имя папки не менять, иначе после обновления будет два плагина.
- Пункт меню — в общем подменю «Модули → Альтан-Эко» через
  `altan_toolbar.add_to_menu` / `remove_from_menu`: они же ставят на подменю
  логотип компании (`altan_logo.svg`).
- Кнопка — на общей панели «Альтан-Эко» (`altan_toolbar.py`, `objectName`
  `AltanEcoToolbar`). Файл и `altan_logo.svg` одинаковы во всех модулях компании, образцы — в
  `shared/` папки проектов; правятся только там и копируются.
- Сеть — только через `QgsNetworkAccessManager`: обычный `QNetworkAccessManager`
  не видит прокси из настроек QGIS.
- Перед `reply.abort()` отключать `finished` от обработчика: `abort()` сам
  вызывает `finished`, и в окне появлялась ошибка «Operation canceled».
- `QgsVertexMarker` хранит координаты карты, а не WGS 84: при смене СК проекта
  маркер пересчитывается из сохранённой точки WGS 84 (`_reposition_marker`).
- Подсказки DaData — не геокодер: координаты бывают уровня улицы или города.
  Точность — `data.qc_geo`; при `qc_geo >= 3` — предупреждение.
- Nominatim (OSM) — публичный сервер со строгими правилами
  (https://operations.osmfoundation.org/policies/nominatim/): не чаще 1 запроса
  в секунду (`MIN_INTERVAL_MS`, пауза через `QTimer`), только по кнопке — без
  автодополнения и пакетного поиска, повторные запросы из кэша, атрибуция OSM
  в окне, адрес сервера меняется без обновления (`GeoSearchRU/nominatim_url`).
  Пакетный поиск по таблице через публичный Nominatim не делать.
- `QgsNetworkAccessManager` подменяет заголовок User-Agent своим
  («Mozilla/5.0 QGIS/…») — свой задать нельзя. Nominatim требует опознать
  приложение, поэтому оно называет себя через Referer (ссылка на репозиторий).
- Яндекс Геокодер: бесплатный ключ — только для проектов с открытым доступом
  и без сохранения результатов. Пользователь решил сохранять (точка во
  временный слой) — это расширенная лицензия; в README это написано.
- Ключи Яндекса и DaData — никогда в репозиторий (он публичный): каждый
  пользователь вписывает их в окне «Ключи» и проверяет кнопкой «Проверить».
  Для живой проверки разработчиком — `yandex.local.json` (в .gitignore) и
  `tests/run_tests.sh live_yandex.py`.
- Кнопка «Проверить» у Яндекса с секретом пробует подписи по очереди
  (`SIGNATURE_MODES`: ttl, plain) и при ответе 200 запоминает сработавшую в
  `GeoSearchRU/yandex_signature`; на 403 переходит к следующей.
- `QDialog` шлёт `finished` раньше `accepted`: сохранение ключей и удаление
  окна «Ключи» — в одном слоте на `finished` (`_keys_closed`), иначе окно
  удаляется до сохранения.
- Подпись Яндекса: base64url(HMAC_SHA256(HMAC_SHA256(secret, "YYYY-MM-DDTHH:00:00Z"), путь+запрос)),
  секрет — base64url; `signature` — последний параметр; URL собирается вручную
  и передаётся через `QUrl.fromEncoded`, чтобы Qt не перекодировал подписанную строку.
- `QgsApplication.initQgis()` переносит `QSettings` в
  `~/Library/Application Support/<организация>/…/profiles/default` — после него
  путь к временному профилю надо задать заново, иначе настройки переживают
  прогон и проверки падают через раз. Папку, созданную `initQgis()`, тесты
  удаляют в конце.
- Кнопка «Что здесь?» с 0.7.1 скрыта: пользователь попросил убрать её из окна,
  код оставлен рабочим. Показывается настройкой `GeoSearchRU/what_is_here`
  (пишется в настройки при первом открытии окна, чтобы её было видно в
  «Параметры → Дополнительно»); окно читает настройку при создании.
  Проверки включают кнопку вызовом `dialog.show_info_button(True)`.
- Overpass («Что здесь?»): `nwr(around:…)` сервер отбивает по таймауту (504) —
  перебор отношений вокруг точки слишком дорог. Запрашиваются `way` и `node`,
  а территории приходят из `is_in`. У площадей из `is_in` в ответе нет
  геометрии, поэтому им ставятся координаты щелчка: точка внутри них и лежит.
  Общественный сервер отвечает 406, если не назваться (curl без `User-Agent`);
  QGIS свой User-Agent ставит сам.
- Сборки QGIS 3.44 и новее (включая QGIS 4) устроены иначе: python лежит в
  `Contents/MacOS/python3.*` и требует `PYTHONHOME=Contents/Frameworks`, пакеты —
  в `Contents/Resources/python<версия>/site-packages`, а `proj.db` переехал из
  `Resources/proj` в `Resources/qgis/proj`. Без верного `PROJ_DATA` пересчёт
  координат молча возвращает исходную точку, и проверки маркера падают.
  Всё это разбирает `tests/run_tests.sh`; другая сборка — через `QGIS_APP=`.
- Настройки временного профиля в проверке настоящим QGIS лежат в
  `<профиль>/profiles/default/qgis.org/QGIS3.ini` (не в `.../QGIS/QGIS3.ini`),
  иначе плагин не включится и `qgis.utils.plugins` будет пустым.
- QGIS падает при выходе, если временный слой добавлен в проект прямо перед
  выходом: воспроизводится и на пустом слое без нашего кода, в проверке это
  не ошибка модуля.
- Обратный геокодинг: DaData — отдельный метод `geolocate/address` (радиус до
  1 км), Яндекс — тот же запрос с `geocode=долгота,широта`, Nominatim —
  соседний адрес `/reverse`, который отвечает одним объектом, а не списком.
- Рамка карты: у Яндекса `bbox=x1,y1~x2,y2` и `rspn=1`, у Nominatim
  `viewbox` и `bounded=1`. DaData рамку не умеет (`SUPPORTS_BBOX = False`):
  её `locations_geo` — это круг, а не прямоугольник.
- Проверки не должны трогать профиль пользователя и не обращаются к DaData и OSM:
  настройки уводятся во временный профиль `tests/_profile`, ответы подменяются,
  Nominatim проверяется на локальном тестовом сервере (заголовки, пауза, кэш).
