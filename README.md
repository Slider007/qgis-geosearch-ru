# Поиск адреса — плагин QGIS

Плагин ищет российские адреса через [подсказки DaData](https://dadata.ru/api/suggest/address/), показывает нормализованный адрес и координаты, переносит карту к найденному месту и ставит на нём временный маркер.

## Возможности

- **До 10 вариантов** на запрос. Если адрес неоднозначный («Ленина 5»), в списке будут все подходящие варианты; при выборе строки карта переходит к нему.
- **Нормализованный адрес** с индексом, регионом и районом.
- **Координаты WGS 84**: широта и долгота с шестью знаками после запятой, их можно скопировать.
- **Точность координат** по данным DaData (`qc_geo`):

  | | точность | масштаб карты |
  |---|---|---|
  | 0 | точные координаты дома | 1:2 500 |
  | 1 | ближайший дом | 1:2 500 |
  | 2 | улица | 1:10 000 |
  | 3 | населённый пункт | 1:50 000 |
  | 4 | город | 1:100 000 |

  Если координаты не точнее населённого пункта, плагин предупреждает об этом оранжевым: маркер стоит в центре посёлка или города, а не у дома. Вариант без координат помечается «без координат», и маркер не ставится.
- **Маркер** — красный крестик на карте. Он пересчитывается при смене системы координат проекта и убирается кнопкой «Очистить маркер» или новым поиском. В проект и в слои ничего не записывается.
- **Точка во временный слой.** Кнопка «Добавить точку во временный слой» кладёт выбранный адрес точкой в слой «Найденные адреса» (EPSG:4326) с полями «Адрес», «Широта», «Долгота», «Точность» и «Код точности DaData». Слой один на все поиски: новые точки добавляются в него, тот же адрес второй раз не добавляется. Если слой удалить, при следующем добавлении он создастся заново. Слой временный (в памяти): чтобы точки не пропали после закрытия QGIS, сохраните его в файл, например модулем «Сохранение временных слоёв в папку».
- **Сеть** — через настройки QGIS (в том числе прокси). Таймаут — 15 секунд.
- **Понятные ошибки**: неверный токен, исчерпан дневной лимит, слишком много запросов, нет связи.

## Установка

1. Скачайте `GeoSearchRU-<версия>.zip` со страницы [Releases](https://github.com/Slider007/qgis-geosearch-ru/releases/latest).
2. В QGIS откройте «Модули → Управление модулями → Установить из ZIP», выберите архив и нажмите «Установить модуль».
3. Во вкладке «Установленные» включите **«Поиск адреса»**.

Кнопка появится на общей панели инструментов модулей компании «Альтан-Эко» (её можно открепить и перетащить), пункт — в меню «Модули → Альтан-Эко».

## Токен DaData

Нужен API-ключ DaData: зарегистрируйтесь на [dadata.ru](https://dadata.ru), ключ будет в [личном кабинете](https://dadata.ru/profile/#info). Надпись «Токен DaData» в окне модуля — ссылка туда же. Бесплатного тарифа хватает на 10 000 запросов в день. Секретный ключ не нужен.

Если отмечено «Запомнить токен на этом компьютере», токен хранится в настройках профиля QGIS открытым текстом. На общем компьютере галочку лучше снять: тогда токен придётся вводить при каждом запуске QGIS.

## Использование

1. Нажмите кнопку «Поиск адреса» на панели «Альтан-Эко» или выберите «Модули → Альтан-Эко → Поиск адреса…».
2. Введите токен и адрес, например `Тамбов, Энергетиков 7`, и нажмите Enter или «Найти».
3. Выберите нужный вариант в списке. Смотрите на точность: если она «город» или «населённый пункт», уточните адрес.
4. Чтобы сохранить адрес на карте, нажмите «Добавить точку во временный слой».

## Совместимость

QGIS 3.40 и новее. Код подготовлен для QGIS 4 (Qt6), но пока проверен только на QGIS 3.40 LTR под macOS.

## Разработка

Структура:

```
GeoSearchRU/              код плагина (эта папка и есть плагин)
  geosearch_ru.py         запрос к DaData, разбор ответа, маркер и карта
  geosearch_ru_dialog.py  окно плагина
  altan_toolbar.py        общая панель модулей компании (одинаковый файл во всех модулях)
tests/                    проверки без интерфейса QGIS и без обращения к DaData
build_zip.sh              сборка zip для установки
```

Запуск проверок на Python из установленного QGIS (macOS):

```bash
tests/run_tests.sh
```

Сборка архива для установки (попадёт в `dist/`):

```bash
./build_zip.sh
```

Чтобы правки сразу подхватывались в QGIS, можно вместо копии поставить ссылку на папку плагина:

```bash
ln -s "$PWD/GeoSearchRU" ~/Library/Application\ Support/QGIS/QGIS3/profiles/default/python/plugins/
```
