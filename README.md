# Поиск адреса — плагин QGIS

Плагин ищет российские адреса через [подсказки DaData](https://dadata.ru/api/suggest/address/), [Яндекс Геокодер](https://yandex.ru/maps-api/docs/geocoder-api/index.html) или [OpenStreetMap (Nominatim)](https://nominatim.org/), показывает нормализованный адрес и координаты, переносит карту к найденному месту и ставит на нём временный маркер.

## Источники

Источник выбирается в окне, выбор запоминается.

| | DaData | Яндекс | OpenStreetMap (Nominatim) |
|---|---|---|---|
| Ключ | токен, бесплатный | ключ «API Геокодера» и, если включена подпись, секрет | не нужен |
| Точность по домам | хорошая, по ФИАС | хорошая | заметно хуже: многих домов, особенно в сёлах, в OSM нет |
| Адрес | нормализованный, с индексом | с индексом, если он известен Яндексу | как записан в OSM |
| Ограничения | 10 000 запросов в день на токен | суточный лимит по лицензии | не чаще 1 запроса в секунду **на всех пользователей вместе** |

**Яндекс: лицензия.** По [условиям Яндекса](https://yandex.ru/dev/commercial/doc/ru/) бесплатный ключ — только для проектов с открытым доступом и **без сохранения** полученных данных. Кнопка «Добавить точку во временный слой» с результатом Яндекса — это сохранение: для неё нужна расширенная коммерческая лицензия.

**Яндекс: ключ и подпись.** Ключ пакета «API Геокодера» берётся в [Кабинете разработчика](https://developer.tech.yandex.ru/) — надпись «Ключ Яндекса» в окне ведёт туда же; ключ начинает работать через 15 минут после получения. Если в настройках ключа включена [подпись запросов](https://yandex.ru/maps-api/docs/common/security/signature_usage.html), введите и секрет подписи — модуль подписывает запросы секретом и временем (рекомендуемый вариант). Для подписи «только секретом» задайте в «Настройки → Параметры → Дополнительно» ключ `GeoSearchRU/yandex_signature` = `plain`.

**Правила публичного сервера Nominatim** ([полный текст](https://operations.osmfoundation.org/policies/nominatim/)) — модуль их соблюдает, а пользователю важно знать:

- только поиск по кнопке: автодополнение и **массовый поиск** (списки адресов, перебор) запрещены — за это сервер блокирует;
- лимит 1 запрос в секунду общий для всех, кто пользуется модулем; модуль сам выдерживает паузу, а повторный запрос того же адреса берёт из памяти;
- данные © участники OpenStreetMap, лицензия ODbL — в окне при выборе OSM показывается атрибуция; небольшие выборки (точки во временном слое) допустимы;
- не отправлять персональные данные и конфиденциальные сведения.

Если OSM попросит сменить сервер или компания поднимет свой Nominatim, адрес меняется без обновления модуля: «Настройки → Параметры → Дополнительно», ключ `GeoSearchRU/nominatim_url` (появляется после первого поиска через OSM; например, `https://nominatim.example.ru/search`). Пустое значение — публичный сервер.

## Возможности

- **До 10 вариантов** на запрос. Если адрес неоднозначный («Ленина 5»), в списке будут все подходящие варианты; при выборе строки карта переходит к нему.
- **Нормализованный адрес** с индексом, регионом и районом.
- **Координаты WGS 84**: широта и долгота с шестью знаками после запятой, их можно скопировать.
- **Точность координат.** У DaData — по полю `qc_geo`:

  | | точность | масштаб карты |
  |---|---|---|
  | 0 | точные координаты дома | 1:2 500 |
  | 1 | ближайший дом | 1:2 500 |
  | 2 | улица | 1:10 000 |
  | 3 | населённый пункт | 1:50 000 |
  | 4 | город | 1:100 000 |

  У Яндекса — по полю `precision` (точный дом, другой корпус, ближайший дом, приблизительно, улица), а если дом не найден — по типу объекта (район, населённый пункт, регион).

  У OpenStreetMap — по типу найденного объекта: дом (1:2 500), улица (1:10 000), населённый пункт или район (1:50 000), город или крупнее (1:100 000).

  Если координаты не точнее населённого пункта, плагин предупреждает об этом оранжевым: маркер стоит в центре посёлка или города, а не у дома. Вариант без координат помечается «без координат», и маркер не ставится.
- **Маркер** — красный крестик на карте. Он пересчитывается при смене системы координат проекта и убирается кнопкой «Очистить маркер» или новым поиском. В проект и в слои ничего не записывается.
- **Точка во временный слой.** Кнопка «Добавить точку во временный слой» кладёт выбранный адрес точкой в слой «Найденные адреса» (EPSG:4326) с полями «Адрес», «Широта», «Долгота», «Точность» и «Источник» (DaData, Яндекс или OpenStreetMap). Слой один на все поиски: новые точки добавляются в него, тот же адрес второй раз не добавляется. Если слой удалить, при следующем добавлении он создастся заново. Слой временный (в памяти): чтобы точки не пропали после закрытия QGIS, сохраните его в файл, например модулем «Сохранение временных слоёв в папку».
- **Сеть** — через настройки QGIS (в том числе прокси). Таймаут — 15 секунд.
- **Понятные ошибки**: неверный токен, исчерпан дневной лимит, слишком много запросов, отказ сервера, нет связи.

## Установка

1. Скачайте `GeoSearchRU-<версия>.zip` со страницы [Releases](https://github.com/Slider007/qgis-geosearch-ru/releases/latest).
2. В QGIS откройте «Модули → Управление модулями → Установить из ZIP», выберите архив и нажмите «Установить модуль».
3. Во вкладке «Установленные» включите **«Поиск адреса»**.

Кнопка появится на общей панели инструментов модулей компании «Альтан-Эко» (её можно открепить и перетащить), пункт — в меню «Модули → Альтан-Эко».

## Токен DaData и ключ Яндекса

Нужен API-ключ DaData: зарегистрируйтесь на [dadata.ru](https://dadata.ru), ключ будет в [личном кабинете](https://dadata.ru/profile/#info). Надпись «Токен DaData» в окне модуля — ссылка туда же. Бесплатного тарифа хватает на 10 000 запросов в день. Секретный ключ не нужен.

Ключ Яндекса — см. «Источники» выше. Если отмечено «Запомнить ключи на этом компьютере», токен, ключ и секрет хранятся в настройках профиля QGIS открытым текстом, у каждого источника свои. На общем компьютере галочку лучше снять: тогда токен придётся вводить при каждом запуске QGIS.

## Использование

1. Нажмите кнопку «Поиск адреса» на панели «Альтан-Эко» или выберите «Модули → Альтан-Эко → Поиск адреса…».
2. Выберите источник. Для DaData введите токен, для Яндекса — ключ (и секрет, если включена подпись). Введите адрес, например `Тамбов, Энергетиков 7`, и нажмите Enter или «Найти».
3. Выберите нужный вариант в списке. Смотрите на точность: если она «город» или «населённый пункт», уточните адрес.
4. Чтобы сохранить адрес на карте, нажмите «Добавить точку во временный слой».

## Совместимость

QGIS 3.40 и новее. Код подготовлен для QGIS 4 (Qt6), но пока проверен только на QGIS 3.40 LTR под macOS.

## Разработка

Структура:

```
GeoSearchRU/              код плагина (эта папка и есть плагин)
  geosearch_ru.py         поиск, кэш и пауза между запросами, маркер, временный слой
  providers.py            запросы к DaData, Яндексу и Nominatim, подпись Яндекса, разбор ответов
  geosearch_ru_dialog.py  окно плагина
  altan_toolbar.py        общая панель и подменю модулей компании (одинаковый файл во всех модулях)
  altan_logo.svg          логотип компании для подменю
tests/                    проверки без интерфейса QGIS и без обращения к сервисам;
                          live_yandex.py — живая проверка Яндекса с ключом из yandex.local.json
build_zip.sh              сборка zip для установки
```

Запуск проверок на Python из установленного QGIS (macOS):

```bash
tests/run_tests.sh
```

Сборка архива для установки (попадёт в `dist/`):

```bash
./build_zip.sh
```

Чтобы правки сразу подхватывались в QGIS, можно вместо копии поставить ссылку на папку плагина:

```bash
ln -s "$PWD/GeoSearchRU" ~/Library/Application\ Support/QGIS/QGIS3/profiles/default/python/plugins/
```
